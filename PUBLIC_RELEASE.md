# Public release boundary

This repository is the maintained public source mirror for RedAgent. It has an independent history
and receives curated, one-way source updates. Private development records, evaluation logs, research
notes, local state, and credentials are not part of this repository.

The current edition is a pre-release and does not claim production or general-availability
qualification. Runtime safety controls remain fail-closed: active capabilities require explicit
authorization, owned scope, policy approval, and auditable evidence.

The repository contains exact compatibility identifiers where changing them would invalidate signed
attestations, migration ordering, or runtime contracts. Those identifiers are technical compatibility
data, not links to private development records.
